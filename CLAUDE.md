Stigsim (Stigmergy Simulator) is a simulation tool for the Stigmergy Workshop at the **Protocol Symposium 2026**, run by the Protocol Institute's SIGFPT (Formal Protocol Theory) group. It demonstrates stigmergic coordination — indirect coordination through traces left in a shared environment — as a formal protocol theory concept.
